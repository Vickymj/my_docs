### Count Word Frequency
Define a function to count the frequency of words in a given list of words.
```py
#Example:

words = ['apple', 'orange', 'banana', 'apple', 'orange', 'apple'] 
count_word_frequency(words) 
#Output:

 {'apple': 3, 'orange': 2, 'banana': 1}

#Solution:
def count_word_frequency(words):
    word_count = {}
    for word in words:
        word_count[word] = word_count.get(word, 0) + 1
    return word_count


```

### Common Keys
Define a function with takes two dictionaries as parameters and merge them and sum the values of common keys.
```py
Example:

dict1 = {'a': 1, 'b': 2, 'c': 3}
dict2 = {'b': 3, 'c': 4, 'd': 5}
merge_dicts(dict1, dict2)
Output:

{'a': 1, 'b': 5, 'c': 7, 'd': 5}

Solution:
def merge_dicts(dict1, dict2):
    result = dict1.copy()
    for key, value in dict2.items():
        result[key] = result.get(key, 0) + value
    return result


```

### Key with the Highest Value
Define a function which takes a dictionary as a parameter and returns the key with the highest value in a dictionary.
```py
Example:

my_dict = {'a': 5, 'b': 9, 'c': 2}
max_value_key(my_dict))
Output:

b
Solution:
def max_value_key(my_dict):
    return max(my_dict, key=my_dict.get)

```

### Reverse Key-Value Pairs
Define a function which takes as a parameter dictionary and returns a dictionary in which everse the key-value pairs are reversed.
```py
Example:

my_dict = {'a': 1, 'b': 2, 'c': 3}
reverse_dict(my_dict)
Output:

{1: 'a', 2: 'b', 3: 'c'}
Solution:
def reverse_dict(my_dict):
    return {v: k for k, v in my_dict.items()}



```

### Conditional Filter
Define a function that takes a dictionary as a parameter and returns a dictionary with elements based on a condition.


```py

Example:

my_dict = {'a': 1, 'b': 2, 'c': 3, 'd': 4} 
filtered_dict = filter_dict(my_dict, lambda k, v: v % 2 == 0) 
Output:

{'b': 2, 'd': 4}
Solution:
def filter_dict(my_dict, condition):
    return {k: v for k, v in my_dict.items() if condition(k, v)}

```

list1 = [1, 2, 3, 2, 1]
