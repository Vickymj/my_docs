## Accessing Values in Lists
| Method | Description | Example |
|--------|-------------|---------|
| **Accessing List Items with Indexing** | Accesses a single item from the list using its index position. Indexing starts from `0`. | `nums = [10, 20, 30]` <br/> `nums[1]` → `20` |
| **Access List Items with Slice Operator** | Accesses a range of items from the list using the slice operator `[start:end]`. | `nums = [10, 20, 30, 40, 50]` <br/> `nums[1:4]` → `[20, 30, 40]` |

## Python - Change List Items
| Method | Description | Example |
|--------|-------------|---------|
| **Change List Items** | Changes a specific item in the list using its index. | `nums = [10, 20, 30]` <br/> `nums[1] = 25` → `[10, 25, 30]` |
| **Change a Range of List Items** | Changes multiple items in a list using slice assignment. | `nums = [10, 20, 30, 40]` <br/> `nums[1:3] = [25, 35]` → `[10, 25, 35, 40]` |

## Python - Add List Items
| Method | Description | Example |
|--------|-------------|---------|
| `append()` | Adds a single item to the end of the list. | `nums = [1, 2]` <br/> `nums.append(3)` → `[1, 2, 3]` |
| `extend()` | Adds multiple items from another sequence to the end of the list. | `nums = [1, 2]` <br/> `nums.extend([3, 4])` → `[1, 2, 3, 4]` |
| `insert()` | Inserts an item at a specified position in the list. | `nums = [1, 3]` <br/> `nums.insert(1, 2)` → `[1, 2, 3]` |


## Python - Remove List Items
| Method | Description | Example |
|--------|-------------|---------|
| `remove()` | Removes the first occurrence of the specified item from the list. | `nums = [10, 20, 30]` <br/> `nums.remove(20)` → `[10, 30]` |
| `pop()` | Removes and returns the item at the specified index. If no index is given, removes the last item. | `nums = [10, 20, 30]` <br/> `nums.pop()` → `30` |
| `clear()` | Removes all items from the list. | `nums = [10, 20, 30]` <br/> `nums.clear()` → `[]` |
| `del` | Deletes a specific item, slice, or the entire list. | `nums = [10, 20, 30]` <br/> `del nums[1]` → `[10, 30]` |

## Python - Loop Lists

| Method | Description | Example |
|------|----------------------|---------|
| **for loop**  | Used to iterate through each item in a list. <br/><br/> **Syntax:** `for item in list:` | `nums = [1, 2, 3]` <br/> `for item in nums:` <br/> `    print(item)` |
| **while loop**  | Used to iterate through list items using a condition. <br/><br/> **Syntax:** `while condition:` | `nums = [1, 2, 3]` <br/> `i = 0` <br/> `while i < len(nums):` <br/> `    print(nums[i])` <br/> `    i += 1` |
| **Loop Through List Items with Index (`range`)** |  Iterates through list items using indexes generated by `range()`. <br/><br/> **Syntax:** `for i in range(len(list)):` | `nums = [1, 2, 3]` <br/> `for i in range(len(nums)):` <br/> `    print(nums[i])` |
| **Iterate using List Comprehension** |  Creates a new list by iterating through an iterable. <br/><br/> **Syntax:** `[expression for item in iterable]` | `nums = [1, 2, 3]` <br/> `squares = [x*x for x in nums]` <br/> `print(squares)` |
| **Iterate using the `enumerate()` Function** |  Iterates through items along with their index values. <br/><br/> **Syntax:** `for index, item in enumerate(iterable):` | `nums = [10, 20, 30]` <br/> `for index, item in enumerate(nums):` <br/> `    print(index, item)` |

## Python List Comprehension
| Sr.No | Method & Description | Example |
|------|----------------------|---------|
| `List Comprehension` |  A concise way to create lists in Python. <br/><br/> **Syntax:** `[expression for item in iterable]` | `nums = [1, 2, 3, 4]` <br/> `squares = [x*x for x in nums]` <br/> `print(squares)` |
| `List Comprehensions and Lambda`  | Uses `lambda` expressions inside list comprehension for compact operations. <br/><br/> **Syntax:** `[(lambda x: expression)(item) for item in iterable]` | `nums = [1, 2, 3]` <br/> `result = [(lambda x: x*2)(n) for n in nums]` <br/> `print(result)` |
| `Nested Loops in Python List Comprehension` |   Uses multiple loops inside a list comprehension. <br/><br/> **Syntax:** `[expression for item1 in iterable1 for item2 in iterable2]` | `pairs = [(x, y) for x in [1, 2] for y in [3, 4]]` <br/> `print(pairs)` |
| `Conditionals in Python List Comprehension` |  Adds conditions while creating lists. <br/><br/> **Syntax:** `[expression for item in iterable if condition]` | `nums = [1, 2, 3, 4, 5]` <br/> `even = [x for x in nums if x % 2 == 0]` <br/> `print(even)` |

## Python - Sort Lists
| Method | Description | Example |
|------|----------------------|---------|
| `sort()` |  Sorts the original list in ascending order by default. <br/><br/> **Syntax:** `list_name.sort(key=None, reverse=False)` <br/><br/> `key` → Function used for custom sorting. <br/> `reverse` → If `True`, sorts in descending order. | `nums = [4, 1, 3, 2]` <br/> `nums.sort()` <br/> `print(nums)` |
| `sorted()` |  Returns a new sorted list without changing the original list. <br/><br/> **Syntax:** `sorted(iterable, key=None, reverse=False)` | `nums = [4, 1, 3, 2]` <br/> `result = sorted(nums)` <br/> `print(result)` |

Key Example:
| Method | Description | Example |
|------|----------------------|---------|
| `Sorting with Callback Function` | Uses the `key` parameter with a built-in function for custom sorting. <br/><br/> **Syntax:** `list_name.sort(key=function_name)` | `list1 = ["Banana", "apple", "Cherry"]` <br/> `list1.sort(key=str.lower)` <br/> `print(list1)` |
| `Using User-defined Function as key Parameter` |  A custom function can be passed to the `key` parameter for special sorting logic. | `def myfunction(x):` <br/> `    return x % 10` <br/><br/> `list1 = [17, 23, 46, 51, 90]` <br/> `print("list before sort", list1)` <br/> `list1.sort(key=myfunction)` <br/> `print("list after sort :", list1)` |

## Python - Copy Lists
| Sr.No | Method & Description | Example |
|------|----------------------|---------|
| 1 | `Shallow Copy on a Python List` <br/> Creates a new list object, but nested objects are still shared between both lists. | `import copy` <br/> `list1 = [[1, 2], [3, 4]]` <br/> `list2 = copy.copy(list1)` <br/> `print(list2)` |
| 2 | `Deep Copy on a Python List` <br/> Creates a completely independent copy of the list including nested objects. | `import copy` <br/> `list1 = [[1, 2], [3, 4]]` <br/> `list2 = copy.deepcopy(list1)` <br/> `print(list2)` |
| 3 | `Copying List Using Slice Notation` <br/> Creates a shallow copy of the list using slicing. | `list1 = [1, 2, 3, 4]` <br/> `list2 = list1[:]` <br/> `print(list2)` |
| 4 | `Copying List Using the list() Function` <br/> Creates a shallow copy using the `list()` constructor. | `list1 = [1, 2, 3, 4]` <br/> `list2 = list(list1)` <br/> `print(list2)` |

## Join Lists in Python
| Sr.No | Method & Description | Example |
|------|----------------------|---------|
| 1 | `Join Lists Using Concatenation Operator` <br/> Combines two or more lists using the `+` operator. | `list1 = [1, 2]` <br/> `list2 = [3, 4]` <br/> `result = list1 + list2` <br/> `print(result)` |
| 2 | `Join Lists Using List Comprehension` <br/> Creates a new list by iterating through existing lists. <br/><br/> **Syntax:** `new_list = [expression for item in iterable]` | `list1 = [1, 2]` <br/> `list2 = [3, 4]` <br/> `result = [x for x in list1 + list2]` <br/> `print(result)` |
| 3 | `Join Lists Using append() Function` <br/> Adds items one by one from another list using a loop. | `list1 = [1, 2]` <br/> `list2 = [3, 4]` <br/> `for item in list2:` <br/> `    list1.append(item)` <br/> `print(list1)` |
| 4 | `Join Lists Using extend() Function` <br/> Adds all elements of one list to another list. | `list1 = [1, 2]` <br/> `list2 = [3, 4]` <br/> `list1.extend(list2)` <br/> `print(list1)` |
