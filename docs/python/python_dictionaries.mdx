## Python - Dictionaries

| Topic | Description | Example |
|---|---|---|
| **Creating Dictionary Using Curly Braces** | Creates a dictionary using `{}` syntax. | `student = {"name": "John", "age": 20}` |
| **Creating Dictionary Using dict() Function** | Creates a dictionary using `dict()` constructor. | `student = dict(name="John", age=20)` |

---

## Accessing Dictionary Items

| Method | Description | Example |
|---|---|---|
| **Using Square Brackets []** | Accesses value using key. | `student["name"]` |
| **Using get() Method** | Returns value safely without error if key not found. | `student.get("name")` |

---

## Modifying Dictionary Items

| Method | Description | Example |
|---|---|---|
| **Modify Existing Value** | Changes value of existing key. | `student["age"] = 25` |
| **update() Method** | Updates multiple key-value pairs. | `student.update({"city":"NY"})` |
| **Conditional Modification** | Modifies value based on condition. | `if "age" in student:` |
| **Add New Key-Value Pair** | Adds new item into dictionary. | `student["course"] = "Python"` |
| **Using setdefault()** | Adds key with default value if missing. | `student.setdefault("marks", 0)` |

---

## Removing Dictionary Items

| Method | Description | Example |
|---|---|---|
| **Using del Keyword** | Removes item using key. | `del student["age"]` |
| **Using pop() Method** | Removes specified key and returns value. | `student.pop("age")` |
| **Using popitem() Method** | Removes last inserted item. | `student.popitem()` |
| **Using clear() Method** | Removes all items from dictionary. | `student.clear()` |

---

## Iterating Through a Dictionary

| Method | Description | Example |
|---|---|---|
| **Loop Through Keys** | Iterates through keys. | `for key in d:` |
| **Loop Through Values** | Iterates through values. | `for value in d.values():` |
| **Loop Through Key-Value Pairs** | Iterates through both keys and values. | `for k,v in d.items():` |

---

## Properties of Dictionary Keys

| Property | Description |
|---|---|
| **No Duplicate Keys** | Duplicate keys are not allowed in dictionaries. |
| **Keys Must Be Immutable** | Keys must be immutable types like string, number, or tuple. |

## Python Dictionary Operators

```py
d1 = {'a': 2, 'b': 4, 'c': 30}
d2 = {'a1': 20, 'b1': 40, 'c1': 60}

```
| Operator          | Description                                      | Example          |
| ----------------- | ------------------------------------------------ | ---------------- |
| `dict[key]`       | Extract/assign value mapped with key.            | `print(d1['b'])` |
| `dict1 \| dict2`  | Union of two dictionaries.                       | `d3 = d1 \| d2`  |
| `dict1 \|= dict2` | Updates first dictionary with second dictionary. | `d1 \|= d2`      |

## Python - Copy Dictionaries
| Method                  | Description                          | Example            |
| ----------------------- | ------------------------------------ | ------------------ |
| **Shallow Copy**        | Copies references only.              | `d.copy()`         |
| **Using copy() Method** | Creates shallow copy.                | `new_d = d.copy()` |
| **Using dict() Method** | Creates dictionary copy.             | `new_d = dict(d)`  |
| **Deep Copy**           | Creates completely independent copy. | `copy.deepcopy(d)` |

## Python - Nested Dictionaries
| Method                          | Description                            | Example                        |
| ------------------------------- | -------------------------------------- | ------------------------------ |
| **Direct Assignment**           | Creates nested dictionary directly.    | `emp = {"e1":{"name":"John"}}` |
| **Using Loop**                  | Creates nested dictionary dynamically. | `for i in range(3):`           |
| **Adding Items**                | Adds new nested items.                 | `emp["e2"] = {"name":"Sam"}`   |
| **Accessing Using Indexing**    | Access nested values directly.         | `emp["e1"]["name"]`            |
| **Using get() Method**          | Safely access nested values.           | `emp.get("e1")`                |
| **Deleting Nested Dictionary**  | Removes nested dictionary item.        | `del emp["e1"]`                |
| **Iterating Nested Dictionary** | Loops through nested dictionaries.     | `for k,v in emp.items()`       |
