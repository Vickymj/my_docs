# Python Functions

Python functions are reusable blocks of code that perform a specific task. Functions help improve code organization, readability, and reusability.

---

# Defining a Python Function

A function in Python is defined using the `def` keyword.

```py
def function_name(parameters):
    "function_docstring"
    function_suite
    return [expression]
```

## Example

```py title="example.py"
def greetings():
    "This is the docstring of greetings function"
    print("Hello World")
    return
```

### Explanation

- `def` → Keyword used to define a function
- `greetings` → Function name
- `()` → Parameters list
- `docstring` → Description of the function
- `return` → Sends a value back from the function

# Function Calling Mechanisms

## Call by Value

In call by value:

- A copy of the variable’s value is passed to the function
- Changes made inside the function do **not** affect the original variable

## Call by Reference

In call by reference:

- A reference to the original object is passed
- Changes made inside the function affect the original object

Python uses **object reference passing**.

- Immutable objects (`int`, `str`, `tuple`) behave like call by value
- Mutable objects (`list`, `dict`, `set`) can be modified inside functions

## Example

```py
def testfunction(arg):
    print("ID inside the function:", id(arg))
    arg = arg + 1
    print("New object after increment:", arg, id(arg))

var = 10

print("ID before passing:", id(var))
testfunction(var)
print("Value after function call:", var)
```

### Output Behavior

- Since integers are immutable, `arg = arg + 1` creates a new object
- Original variable `var` remains unchanged

# Types of Python Function Arguments

Python supports different types of arguments.

## 1. Positional (Required) Arguments

Arguments are passed in the correct positional order.

```py
def add(a, b):
    return a + b

print(add(10, 20))
```

---

## 2. Keyword Arguments

Arguments are passed using parameter names.

```py
def student(name, age):
    print(name, age)

student(age=21, name="John")
```

---

## 3. Default Arguments

Default values are used when arguments are not provided.

```py
def greet(name="Guest"):
    print("Hello", name)

greet()
greet("Alice")
```

## Mutable Objects as Default Arguments

Default arguments are evaluated only once when the function is defined.

Using mutable objects as defaults can lead to unexpected behavior.

```py
def fcn(nums, numericlist=[]):
    numericlist.append(nums + 1)
    print(numericlist)

# Function calls
fcn(66)
fcn(68)
fcn(70)
```

### Output

```py
[67]
[67, 69]
[67, 69, 71]
```

### Why This Happens

The same list object is reused across function calls.

### Recommended Approach

```py
def fcn(nums, numericlist=None):
    if numericlist is None:
        numericlist = []

    numericlist.append(nums + 1)
    print(numericlist)
```

---

## 4. Arbitrary or Variable-Length Arguments

Python allows functions to accept any number of arguments.

### `*args` — Arbitrary Positional Arguments

```py
def total(*numbers):
    print(numbers)

total(1, 2, 3, 4)
```

### `**kwargs` — Arbitrary Keyword Arguments

```py
def details(**data):
    print(data)

details(name="Alice", age=25)
```

# Function Annotations

Function annotations provide metadata about parameters and return values.

```py
def myfunction(a: int, b: int) -> int:
    c = a + b
    return c

print(myfunction(56, 88))
print(myfunction.__annotations__)
```

## Output

```py
144
{'a': <class 'int'>, 'b': <class 'int'>, 'return': <class 'int'>}
```

---

# Function Annotations with Expressions

Annotations can also contain descriptive strings.

```py
def total(x: 'marks in Physics', y: 'marks in Chemistry'):
    return x + y

print(total(86, 88))
print(total.__annotations__)
```

# Python Modules

A module is a Python file containing functions, classes, and variables.

## Listing Module Members

```py
print(dir(modulename))

# Example
print(dir(str))
```

---

## `from ... import *`

Imports everything from a module.

```py
from modname import *
```

---

## `import ... as`

Imports a module using an alias.

```py
import math as m

print(m.sqrt(25))
```

---

# Module Attributes

Python modules contain built-in attributes.

```py
import mymodule

print("__file__ attribute:", mymodule.__file__)
print("__doc__ attribute:", mymodule.__doc__)
print("__name__ attribute:", mymodule.__name__)
```

## Common Module Attributes

| Attribute | Description |
|---|---|
| `__file__` | Path of the module file |
| `__doc__` | Module documentation string |
| `__name__` | Name of the module |

# Packing and Unpacking in Python

## Packing Example

Packing collects multiple values into a single variable.

```py
def pack_example(*args):
    print("Packed arguments:", args)

pack_example(1, 2, 3, 'a', 'b')
```

---

## Unpacking Example

Unpacking extracts values from a collection.

```py
def unpack_example(a, b, c):
    print("Unpacked arguments:", a, b, c)

values = [1, 2, 3]

unpack_example(*values)
```
