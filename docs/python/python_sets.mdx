# Python - Sets

| Topic | Description | Example |
|---|---|---|
| **Creating a Set Using Curly Braces** | Creates a set using `{}` syntax. | `my_set = {1, 2, 3}` |
| **Creating a Set Using set() Function** | Creates a set using the `set()` constructor. | `my_set = set([1,2,3])` |
| **Adding Elements Using add()** | Adds a single element into a set. | `my_set.add(4)` |
| **Removing Elements Using remove()** | Removes an element from a set. Raises error if item not found. | `my_set.remove(2)` |
| **Removing Elements Using discard()** | Removes an element safely without error. | `my_set.discard(2)` |
| **Membership Testing** | Checks whether an item exists in a set. | `2 in my_set` |
| **Union Operation** | Combines all unique elements from sets. | `A \| B` |
| **Intersection Operation** | Returns common elements between sets. | `A & B` |
| **Difference Operation** | Returns elements present only in first set. | `A - B` |
| **Symmetric Difference Operation** | Returns uncommon elements from sets. | `A ^ B` |

# Python Set Comprehensions

| Method | Description | Example |
|---|---|---|
| **Basic Set Comprehension** | Creates a set using comprehension syntax. | `{x for x in range(5)}` |
| **Filtering Elements** | Filters elements using condition. | `{x for x in range(10) if x % 2 == 0}` |
| **Nested Set Comprehension** | Uses nested loops inside comprehension. | `{y for x in [[1,2],[3,4]] for y in x}` |
