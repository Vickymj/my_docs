1. What is UML?

UML (Unified Modeling Language) is a standardized visual language used to model software systems. It helps developers design, understand, and communicate system architecture before implementation.

### Diagram:
```text
+-+
|       System         |
+-+
| - components         |
| - interactions       |
+-+
```



## 2. What is a Class Diagram?

A class diagram represents classes, attributes, methods, and relationships.

### Diagram:
```text
+-+
|       Person         |
+-+
| - name: string       |
| - age: int           |
+-+
| + speak()            |
+-+
```



## 3. What is Association?

Association is a relationship where one class uses or knows another.

### Diagram:
```text
+--+ --> +--+
| Teacher   |           | Student   |
+--+           +--+
```

### Explanation:
Association represents a general relationship between two classes. It can be one-way or two-way. It does not imply ownership.



## 4. What is Directed Association?

A one-way relationship where only one class knows the other.

### Diagram:
```text
+--+ --> +--+
| Teacher   |        | Student   |
+--+        +--+
```



## 5. What is Aggregation?

Aggregation is a weak "has-a" relationship.

### Diagram:
```text
+--+
| Department      |
+--+
| - employees     | ◇> Employee
+--+
```

### Explanation:
- Objects are independent
- Deleting one does not affect the other



## 6. What is Composition?

Strong "has-a" relationship.

### Diagram:
```text
+--+
| House           |
+--+
| - rooms         | ◆> Room
+--+
```

### Explanation:
- Strong ownership
- Child cannot exist without parent



## 7. Aggregation vs Composition

### Diagram:
Aggregation:
```text
◇> Employee
```

Composition:
```text
◆> Room
```

### Explanation:
Aggregation is weak ownership, while composition is strong ownership.



## 8. What is Inheritance?

Inheritance allows one class to acquire properties of another.

### Diagram:
```text

        | Animal |
        +--+
            ▲
            |
        +--+
        | Dog    |
        +--+
```



## 9. What is Realization?
