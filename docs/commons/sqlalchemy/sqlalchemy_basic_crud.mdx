## Creating the User

```py
from db import get_db
from models import User, Post, Detail

session = get_db()

user1 = User(
    name='vicky',fullname='Vignesh MJ',
    posts = [
        Post(active=True, 
            details=[
                Detail(content='Header', active=True),
                Detail(content='Body', active=True),
            ])
    ]

    )
user2 = User(
    name='Jaga',fullname='Jagadeeshwari
    )
user3 = User(
    name='Adhiyan',fullname='Adhiyan Kutty
    )

session.add_all([user1, user2, user3])
#if only one user at at time
#then session.add(user1)
session.commit()

```

## Simple Select

```py

from sqlalchemy import select

session = Session(engine)

stmt = select(User).where(User.name.in_(["Vicky", "Adhiyan"]))

for user in session.scalars(stmt):
    print(user)

```

## SELECT with JOIN


```py
stmt = (
    select(Address)
    .join(Address.user)
    .where(User.name == "sandy")
    .where(Address.email_address == "sandy@sqlalchemy.org")
)
sandy_address = session.scalars(stmt).one()
sandy_address
```

<details>
<summary><strong>SQL Query</strong></summary>
SELECT address.id, address.email_address, address.user_id
FROM address JOIN user_account ON user_account.id = address.user_id
WHERE user_account.name = ? AND address.email_address = ?
[...] ('sandy', 'sandy@sqlalchemy.org')
</details>

:::tip Output
sandy_address=Address(id=2, email_address='sandy@sqlalchemy.org')
:::


## Make Changes


```py
stmt = select(User).where(User.name == "patrick")

patrick.addresses.append(Address(email_address="patrickstar@sqlalchemy.org"))
```

commit will handle both flush and comit
```py

```
:::tip Output

:::

| Operation | What It Does |
|------|---------|
| session.delete(obj) | Marks object for deletion | 
| session.flush() | Sends pending SQL to DB | 
| session.commit() | Permanently saves changes |
